# AI Customer Support Prompt Examples

This Python script demonstrates how to use OpenAI's API to simulate AI-powered customer support responses. It showcases three different prompts representing common customer interactions: product information, technical troubleshooting, and complaint handling.

## Language

`python`

## How to Run

1. Ensure you have Python installed.
2. Install the OpenAI library: pip install openai
3. Set your OpenAI API key as an environment variable: export OPENAI_API_KEY='your-api-key'
4. Run the script: python ai_support_demo.py
